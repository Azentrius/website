## 2. The website azentrius.com

### Server log files

When this website is accessed, our web server automatically records the following data in server log files:

- IP address of the requesting computer (anonymised)
- Date and time of access
- Requested URL
- HTTP status code
- Amount of data transferred

This data is processed solely to keep the service running and to analyse errors (Art. 6 (1) (f) GDPR). It is kept for no more than 14 days.

### Cookies

This website uses no cookies and no tracking or analytics services of third parties.

### Audience measurement (Plausible Analytics)

To understand how this website is used, we use **Plausible Analytics**. Plausible is open-source software and is **self-hosted** by Azentrius on its own server at Hetzner Online GmbH (analytics.azentrius.com). No data is passed to the maker of Plausible or to any other third party.

Plausible uses no cookies and stores nothing on your device. When a page is opened, the following is recorded:

- The page opened, clicks on links to other websites and copying of commands
- The referring website (referrer)
- Browser, operating system and device type (derived from the user agent)
- Approximate location at the level of country, region and city (derived from the IP address)

Your IP address is not stored. To count visits within one day, Plausible forms a hash from the IP address, user agent, domain and a random value that changes daily. The random value is deleted after 24 hours; after that, visits can no longer be linked to anyone. Only aggregated statistics are evaluated.

The legal basis is our legitimate interest in privacy-friendly audience measurement (Art. 6 (1) (f) GDPR).

### Fonts

The fonts of this website (DM Sans, DM Serif Display, Red Hat Mono) are stored on our own server and loaded from there. No connection to third parties is made for fonts.

### Links to GitHub

The pages link to the projects' repositories on GitHub. Your browser connects to GitHub only when you follow such a link; GitHub's privacy policy applies there.
